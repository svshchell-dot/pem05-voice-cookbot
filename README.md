# PEm05 — Голосовой кухонный ассистент (Cookbot)

**Статус проекта:** Завершен

Мультимодальный Telegram-бот (MVP), который выступает в роли кухонного помощника. Бот принимает голосовые или текстовые запросы, распознает речь, генерирует рецепты с помощью LLM и озвучивает их ответным голосовым сообщением.

## Стек технологий
* **Python 3.11**, **aiogram 3** (асинхронный Telegram-бот)
* **Yandex Cloud:** YandexGPT Lite (генерация рецептов), SpeechKit STT (распознавание речи), SpeechKit TTS (синтез речи)
* **SQLite** (`aiosqlite`) — хранение избранных рецептов
* **ffmpeg** — конвертация аудиоформатов в `oggopus` для корректной работы STT
* **Docker / Docker Compose** — изоляция и развертывание на VPS

## Функциональные блоки
* **Голосовой ввод:** получение голосового сообщения от пользователя → конвертация в формат `oggopus` через `ffmpeg` → распознавание речи через Yandex SpeechKit STT.
* **Генерация рецептов:** отправка текста (распознанного или введенного вручную) в YandexGPT Lite → получение структурированного ответа (JSON) с тремя вариантами рецептов.
* **Синтез речи:** генерация голосового ответа (название блюда и шаги приготовления) через Yandex SpeechKit TTS (голос `alena`) и отправка пользователю.
* **Избранное:** сохранение понравившихся рецептов в локальную базу данных SQLite (`recipes.db`).
* **Память диалога:** удержание контекста общения (до 12 сообщений).
